# v0.1.0 Release Notes

**Release Date:** 2026-11-18

The first release of the AcademyOS Go SDK and the `academyos` command line.
Keep a course as a [course-spec](https://github.com/academyosio/course-spec)
directory in git, and use `academyos` to check it, push it with its slide
decks, translations, quizzes and recorded narration, pull the academy's copy
back, and publish it.

## Install

```bash
go install github.com/academyosio/academyos-go/cmd/academyos@v0.1.0
export ACADEMYOS_API_KEY=aos_live_…
academyos whoami
```

`ACADEMYOS_API_URL` sets the server; the default is
`https://app.academyos.io`. Plain `http` is allowed only for `localhost`,
`.localhost` names and loopback addresses.

## Commands

```bash
academyos whoami                       # who the key acts for, its academy and scopes
academyos course validate <dir>        # check a course; exits 2 on errors
academyos course push <dir>            # validate, upload what the academy lacks, apply
academyos course push --dry-run <dir>  # report what would change
academyos course pull <dir>            # write the academy's copy of the course here
academyos course pull --course <id> <dir>  # pull a course into an empty directory
academyos course publish <dir>         # publish the course
academyos pronunciations push [path]   # replace the academy's pronunciations
academyos pronunciations get           # print the academy's pronunciations
academyos version
```

- **Push** uploads only the files the academy doesn't already have, applies
  the course, and records the academy's IDs in the directory, so the next
  push updates the same course.
- **Recorded narration** in each deck's `recordings/`, written by
  videoascode's `--recordings` or `--audio-only`, is pushed with the course,
  and AcademyOS plays it with the slides.
- **Pull** writes the course as it was last pushed, into its directory or an
  empty one, and refuses to overwrite local changes without `--force`.

See [Command Line](../cli.md).

## Go SDK

```go
c, err := academyos.New(academyos.Options{APIKey: os.Getenv("ACADEMYOS_API_KEY")})
```

The `academyos` package covers course push, publish and pull,
pronunciations, and lower-level calls, with typed API errors; `coursepkg`
lists the files a course-spec directory needs. Every request the client
makes is checked against the public AcademyOS API document in `openapi/`.
See [Go SDK](../sdk.md).

## Requirements

- Go 1.26 or later, to build it.
- An AcademyOS server with the public course API, and an API key from an
  instructor or admin.
- Courses in the course-spec v0.2.0 format.

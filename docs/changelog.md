## [v0.1.0] - 2026-11-18

### Highlights

- The `academyos` command line: keep a course as a course-spec directory in git, then check it, push it with its slide decks, translations, quizzes and recorded narration, pull the academy's copy back, and publish it
- The Go SDK, `github.com/academyosio/academyos-go/academyos`: an API client with typed errors for the public AcademyOS API, and `coursepkg` for course-spec directories

### Added

- `academyos whoami`: the key's principal, academy and scopes ([`30377cb`](https://github.com/academyosio/academyos-go/commit/30377cb))
- `academyos course validate`: check a course directory, exiting 2 on errors ([`30377cb`](https://github.com/academyosio/academyos-go/commit/30377cb))
- `academyos course push`: validate, upload only the files the academy lacks, apply the course, and record the academy's IDs in the directory; `--dry-run` reports what would change ([`5b3e44e`](https://github.com/academyosio/academyos-go/commit/5b3e44e))
- `academyos course publish`: publish a pushed course ([`30377cb`](https://github.com/academyosio/academyos-go/commit/30377cb))
- `academyos course pull`: write the academy's copy of a course, as last pushed, into its directory, or into an empty one with `--course`; `--dry-run` lists the changes and `--force` overwrites local changes ([`e76eb80`](https://github.com/academyosio/academyos-go/commit/e76eb80))
- `academyos pronunciations push` and `get`: replace and print an academy's pronunciations, with a diff and `--dry-run` ([`f3dbd8e`](https://github.com/academyosio/academyos-go/commit/f3dbd8e))
- `academyos version`, reporting the module version it was built from ([`30377cb`](https://github.com/academyosio/academyos-go/commit/30377cb))
- `academyos` package: `New` with `Options` (API key, URL), typed API errors, course push, publish and pull, pronunciations, and lower-level calls; plain http is allowed only to `localhost`, `.localhost` names and loopback addresses ([`8d05ed4`](https://github.com/academyosio/academyos-go/commit/8d05ed4))
- `coursepkg`: the files a course-spec directory needs, including each deck's recorded narration in `recordings/` ([`3ab0549`](https://github.com/academyosio/academyos-go/commit/3ab0549))
- The public AcademyOS API's OpenAPI document, in `openapi/` ([`0f7ca46`](https://github.com/academyosio/academyos-go/commit/0f7ca46))
